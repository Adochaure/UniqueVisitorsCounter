A simple lifetime count. No cookies, IP tracking, or fingerprinting.

Simple visitor counting for websites

Unique Visitor Counter gives a website a shared lifetime total. Install the npm package, create a site ID with npx uvc init, and add the count to a React app or any browser JavaScript project. The package includes a command line tool for checking the current total.

Who it is for

Use it on personal sites, project pages, blogs, and small products when you want a lifetime visitor count and a simple day-by-day growth graph. It is designed for developers who want lightweight visitor insights without a full analytics suite.

How the count works

The SDK creates a random browser ID and saves it in local storage. The service counts that browser once per site ID and returns the lifetime total. Clearing local storage or changing browsers can create a new ID, so the number is an estimate of unique browsers rather than verified people.

Frequently asked questions

Does it use cookies or track IP addresses?

No. The SDK uses a random ID in local storage; it does not use cookies, IP addresses, or browser fingerprinting to identify visitors.

Can I use it without React?

Yes. Call createCounter() from browser JavaScript or use the package with Vue, Angular, or Svelte. See the JavaScript guide.

How do I install and configure it?

Install unique-visitor-counter, run npx uvc init in your project, and use the generated site ID. Read the quick start and full documentation.

Can I see daily visitor growth?

Yes. Open the analytics page and enter your site ID to see new unique visitors by day for the last 7, 30, or 90 days.
